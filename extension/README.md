# YouTube 本机下载扩展

独立的 Chrome / Edge Manifest V3 扩展。视频解析、下载和音视频合并在浏览器内完成。
使用时无需 Python、Docker、yt-dlp、FFmpeg、本地程序或下载服务器。

## 安装

1. 解压构建好的 ZIP。
2. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），启用“开发者模式”。
3. 选择“加载已解压的扩展”，选中包含 `manifest.json` 的目录。
4. 打开 YouTube 视频，播放几秒，在“分享”旁点击下载按钮；右侧箭头可选择清晰度。
5. 也可以点击浏览器工具栏的扩展图标，在弹窗中直接选择清晰度并下载。

然后刷新一次已打开的 YouTube 页面。若换了目录，请移除旧扩展并加载新的目录，
避免同时启用两份。更新后打开工具栏弹窗，页脚应显示“版本 0.1.6”。

0.1.6 换用红色视频下载图标，扩展管理页、浏览器工具栏和弹窗统一展示；包含 16/24/32/48/128 像素 PNG，适配不同显示缩放。

0.1.5 为“最近下载”列表补充每项任务的进度条、百分比与已下载/预计总大小；当前标签页不是 YouTube 时也能查看。
完成后显示浏览器实际保存的文件大小，已有下载记录会在扩展启动时从浏览器下载记录补全。总大小未知时显示已下载大小和不定进度条。
当前视频任务区域也同步显示大小。

0.1.4 补充最终文件名处理：保存前校验真实媒体类型，按视频标题和所选后缀命名，保存后核验实际名称；下载记录显示实际文件名。
直接音视频地址采用最多 4 路共享并发分片，单片 4 MiB，支持乱序完成、按位置写入、有限重试和取消。

0.1.3 在页面下载按钮下沿显示进度条，下载时在按钮上显示百分比，关闭清晰度菜单或工具栏弹窗后仍然可见。
准备、合并和保存阶段显示相应状态；大小未知时使用不定进度，保存完成前不会显示 100%。
修复合并文件缺少媒体类型，导致 Chrome 将视频保存为 `.txt` 的问题；按选择保存为 `.mp4`、`.webm` 或 `.m4a`。

0.1.2 默认选择最高可用清晰度，不再继承旧视频的清晰度偏好。页面菜单选完后自动收起；
点击主下载按钮会直接启动任务，首次读取格式后也无需再点第二次。
新增从 YouTube 自身解析直接音视频地址的路径，减少对已捕获播放会话的依赖。

0.1.1 修复了工具栏弹窗过窄的问题，当前视频、清晰度和下载操作直接可见。
安装或重新加载时会为已有 YouTube 标签页补充页面按钮；打开弹窗也会检查并恢复按钮。
适配不同操作栏布局；页面暂时找不到操作栏时，在右下角显示备用下载按钮。

## 从源码构建（仅开发者需要）

```sh
cd extension
npm ci
npm run package
```

生成 `dist/` 和 `artifacts/youtube-local-downloader-0.1.6.zip`。

图标源文件为 `assets/icon.svg`，PNG 已包含在源码中。修改图标后运行 `npm run icons` 重新生成尺寸；该开发命令使用 Playwright Chromium，普通构建和最终用户无需运行。

## 支持范围

- Chrome / Edge 120+ 桌面版。
- YouTube 普通视频和 Shorts；清晰度根据视频实际可用格式显示。
- MP4 / WebM 音画合并，音频原格式导出，任务进度与取消，本地最近记录。
- 暂不支持播放列表、频道批量、正在直播的视频、付费/DRM 内容或 MP3 转码。
- 同时处理一个任务，关闭弹窗后继续下载；关闭浏览器会中断任务，可重新开始。
- 对长度已知的直接音视频地址，最多同时下载 4 个分片，音频和视频共享并发上限；长度未知时流式顺序传输。SABR 回退继续使用原播放协议。速度取决于 YouTube 和网络，无法保证提速倍数。

扩展会读取当前 YouTube 视频的播放信息，并在当前页面中向 YouTube 自身请求
可下载的音视频地址，自动使用页面的正常登录态；无需手动导出 Cookie。可用时也会
复用浏览器正在发送的 GoogleVideo 播放会话。直接地址仅在扩展内存中短暂缓存；
会话仅保存在内存级 session 存储中。本地历史不保存 Cookies、
播放令牌或带签名的地址。扩展不使用第三方解析或令牌服务。

YouTube 验证、登录或播放异常时，请在视频页面处理提示，播放几秒，再重新获取格式。
保存位置使用浏览器默认下载目录；文件同名会自动重命名。大型视频需要足够的浏览器
临时存储空间和磁盘空间。安装包采用本地加载方式，未发布到扩展商店。

0.1.2 已完成公开测试短片的 1080p 下载，以及用户提供的约 12 分 53 秒视频
（vTo2a2sC93c）的完整 2160p MP4 下载：AV1 视频、AAC 音频，约 345 MB。
不同视频的可用性仍取决于 YouTube 的响应；遇到验证失败会停止并清理临时文件，
不会把残缺文件标为完成。

## 验证

```sh
npm test
npm run build
npx playwright install chromium
npm run test:extension
```

真实 YouTube 下载验证与隔离的回归测试分别记录；模拟接口通过不代表线上下载成功。
